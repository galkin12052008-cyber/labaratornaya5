 Подробное описание выполненной работы

В ходе выполнения лабораторной работы была спроектирована архитектура и бизнес-процессы системы онлайн-обучения с использованием языка UML.

Предметная область: образовательная платформа, на которой студенты проходят онлайн-курсы. Каждый курс содержит название, описание, преподавателя и список уроков. Система должна рассчитывать прогресс обучения и считать курс пройденным, если завершены все уроки.

В качестве архитектурного паттерна выбран **MVP**, так как он позволяет четко разделить бизнес-логику, отображение и управление интерфейсом, что упрощает тестирование и дальнейшую поддержку кода на PHP.

1. Диаграмма прецедентов (Use Case Diagram)
Определены два основных актора:
Студент — просматривает каталог курсов, записывается на курс, проходит уроки, смотрит свой прогресс.
Администратор — управляет каталогом курсов и уроками.

2. Диаграмма классов (Class Diagram)
Согласно паттерну MVP, система разделена на три слоя:

Model (Модель): сущности `Student`, `Course`, `Lesson`, `Enrollment`, `Progress` и сервис `LearningService`, содержащий бизнес-логику.
View (Представление): `CatalogView`, `LessonView`, `ProgressView` — отвечают только за отображение данных.
Presenter (Презентер):** связующее звено, которое получает события от View, обрабатывает их через Model и возвращает результат обратно во View.

3. Диаграмма последовательности (Sequence Diagram)
Описан сценарий «Завершение урока». Студент нажимает кнопку во View, событие передается Презентеру, который вызывает метод в Сервисе. Сервис обновляет БД, пересчитывает прогресс и возвращает данные Презентеру, который обновляет интерфейс.

4. Диаграмма деятельности (Activity Diagram)
Описан процесс прохождения курса. После завершения каждого урока система проверяет, все ли уроки пройдены. Если да — курс считается завершенным. Если нет — рассчитывается новый процент прохождения и сохраняется в базе данных.

5. Диаграмма состояний (State Machine Diagram)
Описан жизненный цикл записи на курс (`Enrollment`):
   `Enrolled` (Записан) — начальное состояние.
   `InProgress` (В процессе) — студент начал проходить уроки.
  `Completed` (Завершен) — все уроки пройдены.

 6. Диаграмма компонентов (Component Diagram)
Показана высокоуровневая архитектура приложения. Зависимости направлены от View к Presenter, от Presenter к Domain (Model). Слой Infrastructure отвечает за работу с базой данных MySQL.

ВЫВОД
В ходе выполнения лабораторной работы была спроектирована UML-модель системы онлайн-обучения с использованием паттерна MVP. Структурные диаграммы (Class, Component) помогли выделить сущности и разграничить слои Model, View и Presenter. Поведенческие диаграммы (Use Case, Activity, State Machine) описали бизнес-процессы прохождения курсов и жизненный цикл объектов. Диаграмма последовательности (Sequence) наглядно показала механизм взаимодействия Презентера с Моделью и Представлением. Разработанная модель является достаточной базой для последующей реализации системы на PHP.
