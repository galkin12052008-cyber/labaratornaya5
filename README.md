 Цель работы
Спроектировать архитектуру и бизнес-процессы системы онлайн-обучения с использованием языка UML, опираясь на паттерн проектирования MVP.

 Задание
1. Определить акторов системы.
2. Построить Use Case Diagram.
3. Разработать Class Diagram для основных сущностей.
4. Построить Sequence Diagram сценария «Завершение урока».
5. Построить Activity Diagram процесса прохождения курса.
6. Создать State Machine Diagram для записи на курс.
7. Показать архитектуру системы на Component Diagram.
